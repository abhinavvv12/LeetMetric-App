# 🚀 LeetMetric App

A responsive web application that allows users to check and visualize their LeetCode statistics by entering a LeetCode username.

## 🌐 Live Demo

🔗 https://abhinavvv12.github.io/LeetMetric-App/

---

## ✨ Features

- Search any LeetCode username
- View solved problems by difficulty
  - Easy
  - Medium
  - Hard
- View total submissions
- View difficulty-wise submission counts
- Circular progress indicators
- Responsive design for mobile, tablet, and desktop
- Username validation
- Dynamic UI updates using JavaScript

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Fetch API
- LeetCode Statistics API

## 🚀 How to Use

1. Open the website.
2. Enter a valid LeetCode username.
3. Click **Search**.
4. View the user's problem-solving statistics and submission data.
